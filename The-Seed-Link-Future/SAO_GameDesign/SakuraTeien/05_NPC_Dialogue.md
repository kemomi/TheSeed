# NPC 对话脚本：樱庭·离宫

> **上游依赖**：`04_NPC_System.md`（NPC 名册、好感度阈值、dialogue_root）、`00_Baseline_Conventions.md`（`dlg_`/`quest_` ID 空间、CSV 不存台词）
> **下游被依赖**：`DataTables/DT_NPC_SakuraTeien.csv`（dialogue_root 外键）、`07_Combat_Design.md`（战斗教学提示）
> **本地化约定**：本文件是**台词唯一来源**。CSV 只存 `dialogue_id`，不存文本（`00` §3.3）。引擎侧对话系统按 `dlg_id` 从本文件的本地化资源（β 阶段导出为 JSON/PO）读取。α 阶段台词以本文档为准，引擎侧可硬编码或从此文件生成。

## 设计思路

`01` §1.1 立了个规矩：庭园的背景故事不由旁白给出，而由五个 NPC 对同一个问题——「你们为什么不逃」——的五个不同答案拼成。这份对话脚本就是那个规矩的落地。每个人的回答都只从自己的立场出发，且**互相不知道对方的答案**：三乃只关心茶摊今天的生意，椿只守着结界的规矩，源藏只认手里的石头，枫只想着灯笼和路，武者只认刀。玩家走完一圈，五块碎片才在脑子里拼成完整的庭园。

第二，对话要**短**。VR 里玩家是站着的，头显压着脸，没人愿意站着读三百字。所以每条台词控制在两句以内，能用动作（鞠躬、指向、凿石）表达的就不用嘴说。信息密度靠「多次访问 + 好感度解锁」分摊，而不是一次倒完。

第三，对话承担**教学**功能，但不能像教程。枫提示「看它们抬手」，是作为樱守的经验之谈，不是系统弹窗。源藏讲强化，是石匠对手艺的唠叨。把教学藏进角色口吻，玩家记住的是人，不是规则。

## 一、对话节点格式

每个对话节点用统一结构描述，供引擎侧对话系统消费：

```
[dlg_id]
说话人: <name_cn>（<variant>）
动画: <anim_id 或 动作描述>
条件: <触发条件，无则「首次对话」>
台词: "<文本>"
选项:
  - "<选项文本>" -> <跳转 dlg_id 或 动作>
好感度: <本节点解锁所需好感度，无则不标>
```

台词中的 `{player}` 为玩家名占位符，`{cor}` 为货币单位。⚠️ 玩家名在 α 阶段若未设置，回退为「旅人」。

## 二、三乃（Mino）— 茶摊少女

### 2.1 首次对话（Greet）

```
[dlg_mino_first_meet]
说话人: 三乃（mino）
动画: anim_npc_wave（挥手）
条件: 首次进入茶摊分区
台词: "哎呀，生面孔。{player} 是吧？走了这么远的参道，一定渴了。"
选项:
  - "给我来点吃的。" -> [dlg_mino_shop]
  - "这庭园……就你一个人守着茶摊？" -> [dlg_mino_why_stay]
  - "我只是路过。" -> 结束对话
```

### 2.2 商店

```
[dlg_mino_shop]
说话人: 三乃（mino）
动画: idle + 手臂 IK 指向柜台
台词: "樱饼是今早现做的，团子管饱。结晶嘛……贵是贵，关键时刻能救命。"
选项:
  - "打开商店" -> 触发 Trade 状态，加载 shop_mino（见 04 §5.1）
  - "改天再来。" -> [dlg_mino_bye]
```

### 2.3 为何留下（好感度 0 即可触发，主线碎片①）

```
[dlg_mino_why_stay]
说话人: 三乃（mino）
动画: anim_npc_talk
条件: 首次对话选择该项
台词: "逃？往哪逃？外头那些鬼东西比这庭园里多得多。"
     "至少这儿有樱花、有茶、有个能坐下来喘气的亭子。我娘以前说，越乱越要守着一口热茶。"
选项:
  - "你娘呢？" -> [dlg_mino_mother]
  - "……说得也是。" -> [dlg_mino_bye]
```

```
[dlg_mino_mother]
说话人: 三乃（mino）
动画: idle（低头）
台词: "不在了。这茶摊是她的。我守着，就当她还在。"
选项:
  - "对不起。" -> [dlg_mino_bye]（三乃好感 +3）
```

### 2.4 好感度 40：茶点食谱

```
[dlg_mino_recipe]
说话人: 三乃（mino）
动画: anim_npc_talk
好感度: 40
台词: "看你常来，教你个方子——樱饼的叶子要盐渍过才出味。回头给你多放一片。"

```

### 2.5 好感度 60：隐藏对话（碎片①补完）

```
[dlg_mino_hidden]
说话人: 三乃（mino）
动画: idle（望向樱花林方向）
好感度: 60

     "不像鬼。倒像是在……守着什么。你要去的话，小心点，也别急着拔刀。"
选项:
  - "他知道你在这儿吗？" -> [dlg_mino_busho_know]

### 3.3 结界（主线碎片②）

```
[dlg_tsubaki_barrier]
说话人: 椿（tsubaki）
动画: anim_npc_talk
台词: "这庭园四周的樱树与雾，是历代巫女布下的结界。鬼物进不来内庭，只能徘徊在奥之森以北。"
     "但结界……这些年弱了。我一个人，续不了太久的力。"
选项:
  - "那些石灯笼和结界有关？" -> [dlg_tsubaki_lanterns]
  - "我能帮上忙吗？" -> [dlg_tsubaki_quest_hint]
```

```
[dlg_tsubaki_lanterns]
台词: "正是。七盏石灯笼是结界的节点。灯亮着，结界就稳。可最近……一盏盏灭了。"
     "枫一直在重新点亮它们。你若愿意，去帮她，也帮我。"
效果: 引导玩家找枫接 quest_lantern_lighting（见 §五）

[dlg_tsubaki_quest_hint]
台词: "你愿意？……那么，去石灯笼小径找枫。也去枯山水看看源藏——他的锤子，能替你打牢手里的剑。"
效果: 标记枫、源藏位置（世界空间指引，α 可用名牌高亮）
```

### 3.4 为何留下（碎片②补完）

```
[dlg_tsubaki_why_stay]
动画: idle（望向庭园）
台词: "巫女不能离庭。结界系于我身，我走一步，它就薄一分。"
     "这不是囚禁，{player}。是我选的。总得有人守着这最后一处能坐下喝茶的地方。"
```

### 3.5 好感度 60：结界真相（隐藏）

```
[dlg_tsubaki_hidden]
好感度: 60
动画: anim_npc_talk（压低声音）
台词: "告诉你一件枫都不知道的事——结界的中心，不在樱亭，在奥之森的高台。"

     "所以别杀他。杀了他，这庭园撑不过下一个樱吹雪的季節。"
