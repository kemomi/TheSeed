## 设计思路

上游 kemomi 设计包把剑技、切换、数值、Boss 都定义完了，却没有说这些系统**发生在什么地方**。战斗系统需要一个能承载它的空间：足够小到一个人能做完，足够密到走三步就有一次交互，足够有辨识度到玩家一眼知道自己在哪。

「箱庭（Hakoniwa）」正是为此而选的关卡形态。它不是开放世界的缩小版，而是一种**反开放世界**的设计立场：边界封闭、视线可控、每一处摆放都出于人为意图。日式庭园本身就是箱庭艺术——借景、遮断、回游、蹲踞，这些造园手法与关卡设计的视线引导、节奏控制、路径规划是同一套语言。用樱花亭做首个地编场景，等于**让关卡设计师直接继承一千年成熟的空间语法**，而不必从零发明。

从 SAO 的世界观逻辑出发，这个区域也有其位置：艾恩葛朗特第一层是玩家停留最久的一层，起始之镇之外的郊野需要一处「非战斗的喘息地」。樱庭·离宫承担这个职能——它是安全的、美的、可以坐下来的，但它的奥之森又埋着第一处真正的威胁，构成从「新手保护」到「世界是有牙的」的过渡。

## 一、在艾恩葛朗特中的定位

| 项 | 设定 |
|----|------|
| 所属楼层 | 第一层（Floor 1） |
| 与主城镇关系 | 起始之镇西门外，步行约 12 分钟路程（游戏内实际为传送门直达，避免 α 阶段做野外连线） |
| 区域类型 | 独立箱庭区域（Instanced Hakoniwa），非无缝衔接 |
| 安全属性 | **分区安全**：鸟居前至镜池为安全区（不可战斗）；樱花林、奥之森为交战区 |
| 建议等级 | 1–20 级（⚠️ 玩家等级上限上游未定义，本区域按此区间调参） |
| 容纳人数 | α 阶段单人；设计上支持 4 人小队（对应上游 Boss 4 人基准） |
| 通关时长 | 首次 25–35 分钟，重复访问 5–8 分钟 |

### 1.1 背景故事

樱庭·离宫原为艾恩葛朗特某位已故贵族的私家别院，在主城区划外独立存在。贵族死后无人继承，庭园逐渐被系统判定为「无主地」，樱鬼（Sakura Oni）自枯山水的白石间生出。

现居者仅五人：守庭的樱守、凿石的石匠、摆茶摊的少女、驻守奥之森的绯甲武者，以及留在亭中的巫女。他们各自守着庭园的一部分，谁也不肯先走。

这段设定的**设计用途**是给每个 NPC 一个留在原地的理由——玩家问「你们为什么不逃」时，每个人有不同的答案，而这五个答案拼起来就是区域背景故事本身。信息不由旁白给出，而由玩家自己走完一圈后合成。

### 1.2 氛围关键词

| 关键词 | 落地方式 |
|--------|----------|
| 静 | 环境音以风、水、竹筒敲石（鹿威し）为主；无战斗 BGM，进入交战区才起乐 |
| 落 | 樱吹雪全程持续；花瓣落地后 12 秒淡出，不堆积（性能与视觉双重考量） |
| 旧 | 石材带苔痕、木构有褪色、鸟居漆面剥落；不用崭新贴图 |
| 危 | 奥之森的樱树密度骤降、光线转冷、白石上出现爪痕 |

## 二、视觉基调

### 2.1 色彩

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色·樱 | `#F2C6D0` | 花瓣、树冠主色 |
| 副色·樱深 | `#D98FA3` | 树冠暗部、花蕊 |
| 木构 | `#8B5A3C` | 亭柱、桥体 |
| 鸟居朱 | `#B33A2B` | 剥落处露出下层灰木 `#6E6259` |
| 石材 | `#9A968E` | 灯笼、石垣、枯山水白川砂 `#E8E4DC` |
| 苔 | `#6B8055` | 石缝、树根 |
| 水面 | `#4E7A82` | 镜池，高反射低饱和 |
| 奥之森冷调 | `#5C6B7A` | 交战区光照偏色，与安全区形成对比 |

安全区整体色温偏暖（约 5200K 感受），奥之森偏冷（约 6800K 感受）。α 阶段不依赖后期调色，**直接靠定向光颜色与强度差**实现，成本更低且在 Quest 3 上更稳定。

### 2.2 美术风格

**低多边形风格化（Stylized Low-Poly）**，非写实。理由有三：

1. Quest 3 的移动端渲染管线撑不住写实 PBR 全流程，风格化是性能与观感的正解；
2. 风格化对资产精度容错高，适合程序化生成（见 `03_ArtAssetSpec_Procedural.md`）；
3. SAO 原作的美术本身偏动画化而非照片级，风格化更贴合 IP 气质。

具体规格：硬边法线（不平滑组过渡）、顶点色承载明暗变化、贴图仅用 1 张调色板纹理（Palette Texture）而非逐物体 PBR 贴图。这是 Quaternius / KayKit 系 CC0 素材的通行做法，也是本包程序化资产的输出目标。

### 2.3 光照方案

| 项 | 方案 |
|----|------|
| 主光 | 单一 DirectionalLight，模拟午后偏西侧阳光，欧拉角约 `(-52°, 0°, 38°)` |
| 间接光 | 烘焙 Lightmap（静态物体）；α 阶段禁用实时 GI / SDFGI |
| 天空 | 程序化渐变天空球，不使用 HDRI（省纹理内存） |
| 水面 | 顶点动画 + 单通道法线扰动，不做屏幕空间反射 |
| 阴影 | 仅主光投射，分辨率 2048，级联数 2（Quest 3 上限） |
| 夜景点缀 | 石灯笼内为**假光源**：自发光材质球 + 极小范围 OmniLight（半径 1.5m，仅 6 盏开启） |

## 三、音频基调

| 层 | 内容 | 触发 |
|----|------|------|
| 环境底层 | 风声、远处水流 | 全程循环，安全区 |
| 点睛音 | 鹿威し（竹筒敲石）「咚」声 | 每 18–32 秒随机一次，位置固定于枯山水区 |
| 环境底层（冷） | 低频风、木枝断裂声 | 进入奥之森后交叉淡入 |
| 战斗乐 | 太鼓 + 尺八，2 段循环 | 进入交战状态触发，脱战 6 秒后淡出 |
| UI 音 | 水晶质感的清脆短音 | 菜单开合、选中、确认 |
| 命中音 | 肉声闷响 + 金属泛音（对绯甲） | 按敌人类型区分 |

音频全部使用占位素材，α 阶段不做原创配乐。上表的价值在于**把音频事件与游戏状态绑定关系先定死**，后续替换素材时不需要改逻辑。

## 四、与 SAO 系统的接口

本区域作为地编场景，需要向系统层提供以下接口，供上游战斗系统读取：

| 接口 | 数据 | 定义处 |
|------|------|--------|
| 安全区判定 | 玩家坐标 → 是否可战斗 | `SceneLayout_SakuraTeien.json` 的 `zone.safe` 字段 |
| 切换可用判定 | 队友间是否满足 ≤15m 目视 | 由 `02` 的分区尺度保证：最远两点 34m，同区内不超过 15m |
| 敌人刷新 | 分区 → 敌人类型与数量 | `DataTables/DT_Enemy_SakuraTeien.csv` |
| NPC 可交互 | 射线命中 → NPC ID | `DataTables/DT_NPC_SakuraTeien.csv` |
| 存档点 | 巫女所在亭中位置 | `npc_tsubaki`，提供记录结晶功能 |

其中**「同区内两点距离不超过 15m」是一条硬约束**——上游切换系统要求目视队友 ≤15 米，如果分区尺度超过这个值，玩家在 4 人队伍中会出现「明明在同一区却切不过去」的体验断裂。`02_LevelDesign_Hakoniwa.md` 的分区尺寸据此反推。
