## 设计思路

樱庭·离宫在第一层的定位是「新手保护到世界露出獠牙的过渡带」（`01` §1.1）。战斗设计必须服务这个定位：它要让玩家**第一次真正学会用剑技和切换**，而不是被难度劝退。所以这里的敌人是「教具」，不是「挑战」。

具体来说，樱鬼（兵）教会玩家三件事：读前摇、用剑技打断、以及「打中会有反馈」（顿帧 + 音效 + 击退）。樱鬼（刃）教会玩家「不是所有敌人都该硬刚」——它更快、会闪避，逼玩家用切换拉开节奏。绯甲武者则是**区域毕业考**：高护甲逼玩家在进战斗区前先去源藏那里强化武器（`02` §3.1 的软性必经设计），双手持刀的架势和明确的三段连招，检验玩家是否真的掌握了前面学到的一切。

难度曲线因此是「教学 → 应用 → 毕业」，而不是「弱敌 → 强敌」的数值堆叠。每个新敌人引入的是**一个新机制**，不是更高的血条。

第二个原则继承自上游：战斗手感靠**顿帧（Hit Stop）+ 音效 + 击退**三件套，而非伤害数字飘字。上游 Boss 设计里 Hit Stop 取 0.05s，本区域普通敌人沿用并略降（0.04s），保证「打中有感觉」但不打断节奏。VR 里这种物理反馈比屏幕游戏更重要，因为玩家是「亲手」挥剑。

### 2.2 行为树（`BT_SakuraOni_Grunt`）

上游 `BossAI_Phase1_BT.md` 为空，本包为区域敌人定义行为树（格式沿用上游 `BT_` 前缀）：

```
Root (Selector)
├─ Sequence [死亡]
│  ├─ Condition: HP <= 0
│  └─ Action: PlayDie → 尸体淡出
├─ Sequence [受击反应]
│  ├─ Condition: 刚受击 且 未在攻击中
│  └─ Action: PlayHit（可打断当前追击）
├─ Sequence [战斗]
│  ├─ Condition: 玩家在索敌半径内 且 在交战域
│  ├─ Selector
│  │  ├─ Sequence [攻击]
│  │  │  ├─ Condition: 距离 <= 攻击距离 且 攻击冷却完毕
│  │  │  └─ Action: FacePlayer → PlayAttack（打击帧判定伤害）→ 冷却 2.5s
│  │  └─ Sequence [追击]
│  │     ├─ Condition: 距离 > 攻击距离
│  │     └─ Action: MoveToPlayer（NavMesh，速度 1.6）
└─ Action: PlayIdle（巡逻/待机，无玩家时）
```

### 2.3 攻击招式

单一招式，前摇明确（教学目的）：

| 招式 | 前摇 | 打击帧 | 后摇 | 伤害 | 可读性设计 |
|------|------|--------|------|------|-----------|
| 挥砍 | 0.39s | 0.62×dur（`06` §3.2） | 0.4s | 12 | 前摇时身体后仰 + 手臂高举发光，玩家有充分反应时间 |

**教学意图**：前摇 0.39s 足够玩家用剑技（垂直斩前摇更短）抢先打断，或侧身闪避。第一次遇到时游戏会通过枫的对话提示「看它抬手！」（见 `05`）。

| 闪避 | **有**（见 3.3） | 新机制 |
| Hit Stop | 0.04s | 同 |
| 经验值 | 35 | |
| 掉落 | 樱结晶（40%）、强化石（20%）、骨刀素材（15%） | |

### 3.2 行为树差异（`BT_SakuraOni_Blade`）

在兵的行为树基础上增加：

```
├─ Sequence [战斗] 内 Selector 增加分支
│  ├─ Sequence [闪避]（优先级高于追击）
│  │  ├─ Condition: 玩家正在蓄力剑技（武器发光）且 距离 < 3m 且 闪避冷却完毕
│  │  └─ Action: DodgeBack（后跳 2m）→ 冷却 4s
│  └─ Sequence [连击]
│     └─ Action: 攻击命中后 30% 概率接第二段挥砍
```

### 3.3 新机制：闪避

**设计意图**：刃会闪避玩家的剑技，逼玩家改变策略——不能无脑冲上去放剑技，要么用普攻骗出闪避再接剑技，要么用**切换（Switching）**让队友从侧后方攻击（闪避只朝正后方）。这是对上游切换系统的实战教学。

| 参数 | 值 |
|------|-----|
| 触发条件 | 玩家武器发光（剑技准备姿势，上游 `SwordSkillSystem` 的静止 0.3s）且距离 <3m |
| 闪避方向 | 正后方 2m（不侧闪，留切换破绽） |
| 冷却 | 4s |
| 闪避无敌帧 | 闪避动画 0.3s 内免伤 |

⚠️ 单人游玩时无队友切换，刃的闪避会让战斗变慢但不卡关——玩家可用「普攻骗闪避 → 冷却期放剑技」应对。此设计已在单人可通关前提下验证（见 `02` §3.1 黄金路径第 7 步为「兵」×3，刃在 5 级后才加入刷新池）。

## 四、绯甲武者 — 区域守卫（毕业考）

### 4.1 基础数值

数值参照上游 Boss 4 人基准的思路，但作为**区域守卫**（非楼层 Boss）大幅下调，确保单人 α 可通关：

| 属性 | 值 | 备注 |
|------|-----|------|
| HP | 1200 | 区域守卫级，约为兵的 10 倍 |
| 攻击力 | 35（单段）/ 55（重击） | 见招式表 |
| 防御 | 18 | **高护甲**，未强化武器伤害减半 |
| 移动速度 | 2.2 m/s | 中速 |
| 攻击距离 | 2.2m（太刀） | 长 |
| 索敌半径 | 12m | 进入交战域且玩家拔刀即敌对 |
| Hit Stop | 0.05s | 同上游 Boss 取值 |
| 经验值 | 300 | |
| 掉落 | 庭园图残页（100%，`quest_map_fragment`）、绯甲碎片（50%）、太刀·绯（20%） | |

### 4.2 护甲机制（软性必经的落点）

**这是 `02` §3.1「进战斗区前必须强化武器」的机制实现**：

- 绯甲武者防御 18。玩家伤害公式（沿用上游）：`实际伤害 = max(1, 物攻 − 敌防御)`。
- 未强化初始剑物攻约 20 → 实际伤害 2，需 600 次攻击，**不可行**。
- 强化 +3 后物攻约 32 → 实际伤害 14，约 86 次，**勉强可行但漫长**。
- 强化 +5 后物攻约 42 → 实际伤害 24，约 50 次，**合理**。
- 剑技（垂直斩 150%）：+5 强化下 42×1.5−18 = 45，约 27 次剑技，配合普攻与切换可在 3–5 分钟击杀。

结论：玩家**必须**先在源藏处强化到 +5 左右，战斗才流畅。支线「点亮七盏石灯笼」奖励强化石 ×3，正好支撑 +5（+1~+5 消耗递增，3 块强化石 + 科尔可达）。这是刻意的引导闭环。

### 4.3 行为树（`BT_Hikabusho`）

```
Root (Selector)
├─ Sequence [死亡] → PlayDie
├─ Sequence [阶段切换]
│  ├─ Condition: HP < 50%
│  └─ Action: EnterPhase2（速度+20%，解锁连招，播咆哮）
├─ Sequence [战斗]
│  ├─ Condition: 玩家敌对 且 在交战域
│  ├─ Selector
│  │  ├─ Sequence [三段连招]（Phase2，距离<2.5m）
│  │  │  └─ Action: 横斩 → 上挑 → 重劈（每段可被切换/翻滚打断）
│  │  ├─ Sequence [突刺]（距离 2.5–5m）
│  │  │  └─ Action: Charge → Thrust（直线突进 4m）
│  │  ├─ Sequence [重击]（距离<2m，冷却 6s）
│  │  │  └─ Action: PlayAttack（高伤害，长前摇，可打断）
│  │  └─ Sequence [追击] → MoveToPlayer
└─ Action: PlayGuard（非战斗警戒，见 06 §2.3）
```

### 4.4 招式表

| 招式 | 阶段 | 前摇 | 伤害 | 范围 | 可打断 | 应对 |
|------|------|------|------|------|--------|------|
| 横斩 | 1/2 | 0.4s | 35 | 前方扇形 2.2m | 否（但可闪避） | 后撤 / 切换 |
| 上挑 | 2 | 0.35s | 35 | 前方 1.8m | 否 | 侧移 |
| 重劈 | 1/2 | 0.7s | 55 | 前方 2.2m | **是**（剑技打断） | 抢剑技 / 拉距离 |
| 突刺 | 1/2 | 0.5s | 40 | 直线 4m | 否 | 侧闪（直线易躲） |
| 三连斩 | 2 | 0.3s 起 | 35×3 | 前方扇形 | 每段间可切换打断 | 切换连携 |

**Phase2（HP<50%）**：移动速度 +20%，解锁三连斩，攻击欲望提升。咆哮动画（复用 `anim_busho_idle` 加大幅度 + 镜头震动）作为阶段切换演出。

### 4.5 与切换系统的配合

绯甲武者是**切换系统的最佳教具**：
- 三连斩每段之间有 0.3s 间隙，正好够切换（上游切换冷却 1.5s，但瞬移是无敌的）。
- 玩家 A 被压制时切换到玩家 B，武者仇恨强制转移（上游 `SwitchingSystem`：原仇恨 −30%），B 获得输出窗口。
- 2s 内第三次切换伤害 +50% 并破防——对高护甲武者，这是快速削防的关键手段。

单人 α 无队友时，切换不可用，玩家靠「重劈可打断」和「突刺易侧闪」应对，战斗更长但可通关。⚠️ 单人毕业考难度登记为已知限制，多人体验更佳。

## 六、战斗反馈三件套

VR 战斗手感的核心，全部敌人通用：

| 反馈 | 触发 | 参数 |
|------|------|------|
| 顿帧 Hit Stop | 命中瞬间 | 普通敌 0.04s，武者 0.05s（时间缩放至 0.1×） |
| 命中音 | 命中瞬间 | 樱鬼：肉声闷响；武者：金属泛音（`01` §3） |
| 击退/受击动画 | 命中 | 播 `anim_*_hit`，樱鬼（兵）额外后退 0.3m |
| 打击特效 | 命中点 | 白色斩击痕 + 樱花瓣迸溅（粒子，10 片，0.5s） |
| 手柄震动 | 命中 | 轻震 0.05s（武者重击 0.1s） |
| 伤害数字 | ⚠️ α 不飘字 | VR 中飘字干扰沉浸，改用受击动画+音效表达 |

**不飘伤害数字**是刻意的 VR 设计选择——屏幕游戏靠数字给反馈，VR 靠「打中的物理感」。
