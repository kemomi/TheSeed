## 设计思路

箱庭场景里的 NPC 不是任务发放机，而是**空间的人格化**。上一份文档（`01`）说过，这个庭园有五个不肯离开的人，他们各守一处——所以每个 NPC 首先是**一个分区的化身**：茶摊的少女定义了「补给」，巫女定义了「安全」，石匠定义了「成长」，樱守定义了「引路」，武者定义了「威胁」。玩家记住的不是五个名字，而是庭园的五个功能，而功能被赋予了脸。

第二个原则是**交互必须用 XR 的原生语言**。上游 `GestureUISystem.md` 已经定义了手势与环形菜单，本系统在其上叠加「注视 + 射线 + 手势」三通道，但核心是**注视**：在 VR 里，玩家看向谁，谁就该有反应。NPC 必须回看、必须转向、必须有被注视时的微表情——这不是锦上添花，而是 VR 里「这个角色是活的」的唯一可信来源。贴屏 UI 那套「走到范围内弹出对话框」的做法在这里是失败的。

第三个原则是**信息分布，而非集中**。玩家问五个人「你们为什么不逃」，得到五个不同的答案，这五个答案拼起来才是区域背景故事（见 `01` §1.1）。信息不由旁白或单一 NPC 一次性倒出，而由玩家自己走完一圈后合成。这要求每个 NPC 只知道自己那部分，且**知道边界**——三乃不懂战斗，源藏不懂结界，武者不懂人心。

## 二、交互状态机

每名 NPC 是一个有限状态机。状态迁移由**玩家距离、注视、交互输入、敌对标记、好感度**共同驱动。

### 2.1 状态定义

| 状态 | 进入条件 | 行为 | 动画 |
|------|----------|------|------|
| `Idle` | 默认，玩家 >8m | 原地待机，播放环境动画 | `idle`（武者为 `guard`） |
| `Aware` | 玩家进入 8m **或** 注视 NPC | 转向玩家，抬头，轻微前倾 | `idle` + 头部 IK 转向 |
| `Greet` | 首次进入 4m（每个玩家会话一次） | 主动招呼（挥手/点头/鞠躬，按角色） | `wave`（三乃/枫）/ `bow`（椿/源藏） |
| `Talk` | 玩家发起交互（射线选中 + 触发键 / 手势） | 进入对话，播放说话动画 | `talk` |
| `Trade` | 对话中选择「买卖」 | 打开世界空间商店面板 | `idle`（下半身）+ 手臂 IK |
| `Service` | 对话中选择「强化」（源藏） | 打开强化面板，播凿石动作 | `sit` + 手臂 IK |
| `Patrol` | 枫专属，无玩家时 | 沿小径往返巡逻 | `walk` |
| `Hostile` | 武者专属，玩家进入交战域且拔刀 | 转入敌人 AI（见 `07`） | `attack` / `hit` / `die` |
| `Flee` | ⚠️ α 阶段未实现 | — | — |

### 2.3 注视（Gaze）机制

VR 交互的核心。规则：

1. **注视判定**：从 HMD 位置沿视线方向发射射线，命中 NPC 头部包围盒（半径 0.25m）即视为注视。
2. **注视累积**：持续注视 0.4s 触发 `Aware`；0.8s 且距离 <4m 触发 NPC 主动 `Greet`（免按键打招呼）。
3. **NPC 回看**：`Aware` 状态下，NPC 头部骨骼（`Head`）通过 IK 朝向玩家 HMD，但**限制在 ±60°**，超过则整个身体转向（避免脖子拧断）。
4. **注视反馈**：被注视的 NPC 头顶浮现世界空间名牌（姓名 + 职能图标），淡入 0.2s。这是 XR 中替代「准星悬停高亮」的做法。
5. **隐私克制**：NPC 不会在玩家背对时偷偷转向跟随——转身只在 `Aware` 进入时发生一次，避免「被盯着」的不适感。

### 2.4 交互输入映射

沿用上游 `GestureUISystem.md` 的手势语义，叠加控制器方案：

| 交互 | 控制器 | 手部追踪 | 说明 |
|------|--------|----------|------|
| 选中 NPC | 交互射线指向 + 注视 | 食指向 NPC | 世界空间射线，非贴屏 |
| 发起对话 | 扳机键（Trigger） | 捏合手势（拇指+食指） | 上游手势规范 |
| 对话推进 | 扳机键 | 捏合 | 逐句 |
| 打开环形菜单 | 握持键（Grip） | 张开手掌 | 上游环形菜单 |
| 关闭面板 | B/Y 键 | 握拳 | — |

## 三、好感度系统

轻量好感度，α 阶段只做**解锁对话与商店折扣**，不做剧情分支网（见 `00` §5 α 范围）。

### 3.1 数值

| 项 | 规则 |
|----|------|
| 好感度范围 | 0–100，每名 NPC 独立 |
| 初始值 | 20 |
| 首次对话 | +10 |
| 完成该 NPC 关联支线 | +25 |
| 每日（每次进入区域会话）首次问候 | +3 |
| 购买其商品 | +1（单次会话上限 +5） |
| 好感度上限行为 | 达 60 解锁隐藏对话；达 90 解锁折扣（三乃）/ 额外强化槽（源藏） |

### 3.2 好感度阈值与奖励

| 阈值 | 三乃 | 椿 | 源藏 | 枫 |
|------|------|----|------|----|
| 40 | 解锁茶点食谱对话 | 解锁庭园历史对话 | 解锁凿石手法对话 | 解锁樱守职责对话 |
| 60 | 隐藏对话：为何留下 | 隐藏对话：结界真相 | 隐藏对话：石头的记忆 | 隐藏对话：枫与武者 |
| 90 | 商品 9 折 | 存档附带一次免费回复 | +1 强化成功率 | 巡逻时护送玩家过樱花林 |

隐藏对话内容见 `05_NPC_Dialogue.md`。好感度数据表见 `DT_NPC_SakuraTeien.csv`。

## 四、日程系统（α 简化版）

上游无昼夜系统（`02` §8 已登记夜间刷新挂起）。α 阶段 NPC **不做时间驱动的复杂日程**，只做基于「玩家在/不在」和「交互状态」的简单行为切换：

| NPC | 无玩家时 | 玩家在分区时 |
|-----|----------|--------------|
| 三乃 | 立于茶摊后，`idle`，偶尔拭碗 | `Aware` → `Greet` |
| 椿 | 樱亭中静立，`idle` | `Aware` → `Greet`（鞠躬） |
| 源藏 | 坐缘侧凿石，`sit` + 手臂 IK 循环 | 停凿，转 `Aware` |
| 枫 | 沿小径 `Patrol`（往返 6→18m） | 停下，转 `Aware` |
| 绯甲武者 | 高台 `guard` 持刀警戒 | 进入交战域→`Hostile` |

⚠️ 完整昼夜日程（白天/黄昏/夜晚不同位置与对话）登记为 β 阶段需求，α 不实现。

### 5.2 源藏的强化台（服务）

沿用上游 `StatGrowthSystem.md` 的强化规则（+1～+15，成功率递减，+10 以上失败 30% 损毁）。源藏提供：

- **强化服务**：消耗强化石 + 科尔，对武器执行强化。成功率见上游表。
- **好感度 90 奖励**：额外 +1 强化成功率缓冲（失败不降级一次）。
- 支线「点亮七盏石灯笼」奖励强化石 ×3（见 `02` §3.3）。

### 5.3 椿的存档点

- 樱亭为**固定存档点**，与椿对话即可存档（免费）。
- 使用「记录结晶」可在任意安全区存档（消耗道具）。
- 椿好感度 90 时，存档附带一次免费全恢复。

## 六、世界空间 UI

XR 中**禁止贴屏 UI**（`00` §2.2）。所有 NPC 相关 UI 锚定在 3D 空间：

| UI | 锚定 | 形态 |
|----|------|------|
| 名牌 | NPC 头顶 0.3m | 半透明牌，姓名 + 职能图标，注视淡入 |
| 对话框 | NPC 胸前，面向玩家 | 世界空间面板，跟随 NPC 但不遮挡脸 |
| 商店面板 | NPC 右侧 0.8m | 环形/网格菜单（沿用手势系统） |
| 强化面板 | 源藏身前 | 世界空间面板 + 3D 武器预览 |
| 好感度 | 名牌下方细条 | 仅 `Aware` 时显示 |

对话框朝向：始终 billboard 面向玩家 HMD，但**限制在 NPC 前方 120° 锥内**，避免玩家绕到 NPC 背后时面板穿模。

## 七、数据表接口

NPC 静态数据存于 `DataTables/DT_NPC_SakuraTeien.csv`（格式见 `00` §3.3）。字段：

| 列 | 类型 | 说明 |
|----|------|------|
| `npc_id` | string | 主键，如 `npc_mino` |
| `name_cn` | string | 中文名 |
| `name_romaji` | string | 罗马音 |
| `role` | string | 职能标签 |
| `zone_id` | string | 所属分区 |
| `hostile` | bool | 是否敌对 |
| `asset_variant` | string | variant 名（装配映射键） |
| `prop_asset` | string | 手持配件资产 ID |
| `anim_set` | string | 动画集名（见 `06`） |
| `interact_radius_m` | float | 交互触发半径 |
| `greet_radius_m` | float | 主动招呼半径 |
| `default_affinity` | int | 初始好感度 |
| `shop_id` | string | 商店 ID（无则空） |
| `service_id` | string | 服务 ID（无则空） |
| `dialogue_root` | string | 对话根节点 ID（见 `05`） |

好感度阈值与解锁见 `05_NPC_Dialogue.md` 与 `04` §3.2，运行时好感度存于玩家存档，不入 CSV。
