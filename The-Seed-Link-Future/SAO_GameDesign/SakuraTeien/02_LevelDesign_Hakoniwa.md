## 设计思路

箱庭的第一原则是**「一眼看尽却走不完」**。玩家在鸟居前应该能看见镜池、樱亭的一角和远处樱花林的轮廓——视线被给足了，人才愿意往里走；但真走进去，每一段路又都有遮挡和转折，实际步数远多于视线距离。这就是日式庭园的「回遊（Kaiyū）」手法，也是关卡设计里的「视线牵引 + 路径延迟」。

第二原则是**边界必须被看见，但不能被感知为墙**。开放世界用远景山脉糊弄玩家，箱庭不行——它就那么小，四周必须有交代。这里的处理是：南侧以鸟居和石垣明示入口，东西北三侧用密集樱树 + 地形抬升 + 雾浓度递增三重手段，让「走不出去」表现为「没有理由往那走」，而不是撞上一堵空气墙。α 阶段仍需物理碰撞体兜底，但视觉上不出现任何人工边界物。

第三原则是**分区尺度服从战斗系统**。上游切换（Switching）要求目视队友 ≤15 米，这不是一个可以事后迁就的参数——如果分区直径超过 15m，4 人队伍会频繁出现「人在同区却切不动」的断裂感。因此本文档所有分区的**最大对角线严格 ≤15m**，下表逐区给出实测值。这是本设计唯一的硬几何约束，其余都可调。

          (石灯笼小径)              (樱花林, 战斗)

## 三、动线设计

### 3.1 黄金路径（首次通关）

| 序 | 分区 | 玩家在此做什么 | 获得 |
|----|------|----------------|------|
| 1 | 鸟居参道 | 出生点。看见全景。学习移动与交互射线 | 基础操作 |
| 2 | 茶摊 | 与三乃对话，买樱饼（回复道具） | 商店系统、货币概念 |
| 3 | 镜池·太鼓桥 | 观赏。鹿威し首次响起。拾取水面漂浮的记录结晶 | 探索奖励、听觉引导 |
| 4 | 樱亭 | 与椿对话，激活存档点，学习切换系统（若单人则由椿口述） | 存档、切换机制说明 |
| 5 | 枯山水 | 与源藏对话，接受支线「点亮七盏石灯笼」，强化武器 +1 | 强化系统、支线 |
| 6 | 石灯笼小径 | 沿路点亮灯笼（支线进度），气氛转冷 | 紧张感铺垫 |
| 7 | 樱花林 | **首次战斗**。遭遇 3 只樱鬼（兵） | 剑技实战、顿帧反馈 |
| 8 | 奥之森 | **区域守卫战**。绯甲武者 1 + 樱鬼（刃）2 | 完整战斗循环验证 |

关键节点是第 5 步和第 7 步之间——玩家必须在**进入战斗区之前**拿到武器强化，否则绯甲武者的高护甲会让首次体验变成劝退。源藏的强化服务因此不是可选支线，而是**软性必经**：支线任务「点亮七盏石灯笼」的奖励正是强化石，玩家会自然拿到。这是刻意的设计，不是巧合。

### 3.2 回遊路径（重复访问）

完成黄金路径后，玩家解锁两条捷径：

- **西回**：枯山水 → 镜池 → 茶摊 → 参道（用于快速返回商店）
- **北回**：奥之森 → 石灯笼小径 → 樱花林 → 镜池（用于刷怪）

这两条路径让二次访问时长从 30 分钟压缩到 5–8 分钟，符合「日常刷材料」的长期使用形态。

### 3.3 支线与隐藏内容

| ID | 名称 | 触发 | 奖励 |
|----|------|------|------|
| `quest_lantern_lighting` | 点亮七盏石灯笼 | 与源藏对话 | 强化石 ×3、樱吹雪特效变体 |
| `quest_pond_crystal` | 水面上的结晶 | 拾取镜池漂浮物 | 记录结晶（存档道具）×1 |
| `quest_map_fragment` | 缺失的庭园图 | 奥之森绯甲武者掉落 | 解锁枫的隐藏对话（见 `05`） |

## 四、视线设计

日式庭园三法在本关卡的具体落位：

### 4.1 借景（Shakkei）

站在**樱亭平台**（`(11;3)`，视点高 `z:1.95`）向西北望，视线越过镜池水面，收于奥之森的樱树轮廓。距离 28m，但通过水面倒影与前景桥体压缩感知，看起来像 15m 内的景致。

实现要点：此视线上**不得放置任何高于 2m 的遮挡物**。石灯笼小径的灯笼高度 1.6m，刻意压低就是为了不切断这条借景线。

### 4.2 遮断（Shadan）

从**鸟居参道**看向镜池，太鼓桥的拱起桥体（顶点 `z:0.9`）遮挡水面下半部分，玩家看不见池底和北岸。走过桥的瞬间视野突然打开——这是全关卡唯一的「视野爆发点」，留给最有价值的景色。

反例警示：不要在参道上再放第二处遮挡。一次爆发点的力量来自其唯一性。

### 4.3 对景（Taikei）

每个分区的视觉焦点互为对景：

| 观察点 | 对景物 | 距离 |
|--------|--------|------|
| 鸟居下 | 太鼓桥 + 其后樱亭檐角 | 24m |
| 茶摊座位 | 枯山水白川砂纹 | 7m |
| 枯山水缘侧 | 镜池 + 桥 | 12m |
| 石灯笼小径南端 | 樱花林深处的一株独樱 | 11m |
| 奥之森 | 回望时看见整条小径的灯笼序列 | 16m |

### 4.4 视线遮挡与 NPC 可见性

**硬规则：任何 NPC 在玩家进入其所属分区时，必须在视线内可见，或被明确的声音/光效引导。**

理由：XR 中玩家没有小地图（贴屏 UI 在 VR 里体验差），找不到 NPC 是最高频的挫败来源。落地方式：

| NPC | 可见性保障手段 |
|-----|----------------|
| 三乃（茶摊） | 摊顶挂暖色灯笼，24 小时自发光，远距离可见 |
| 椿（樱亭） | 亭内为最高点，从参道即可看见其剪影 |
| 源藏（枯山水） | 凿石声（每 3–6 秒一次）作听觉引导，进入分区必闻 |
| 枫（石灯笼小径） | 手提灯笼，光源跟随移动，暗处最显眼 |
| 绯甲武者（奥之森） | 甲胄反光 + 站立于区域中央高台，无遮挡 |

## 五、垂直层次

箱庭的「小」要靠垂直变化补偿。本区域共 5 个高度层：

| 层级 | 高度 | 位置 | 作用 |
|------|------|------|------|
| L0 水面 | `z:−0.3` | 镜池 | 最低点，倒影与漂浮物 |
| L1 地面 | `z:0.0` | 参道、茶摊、枯山水 | 基准层 |
| L2 桥顶 | `z:0.9` | 太鼓桥拱顶 | 视野爆发点 |
| L3 亭台 | `z:0.45`（地板）／`z:2.2`（檐下） | 樱亭 | 观景与借景 |
| L4 高台 | `z:1.2` | 奥之森 | 守卫战场地，居高临下 |

垂直移动**全部为缓坡或台阶，无跳跃要求**。XR 中跳跃极易引发晕动症，α 阶段完全避免。台阶单级高度 ≤0.15m，坡道坡度 ≤12°。

## 六、碰撞、导航与边界

### 6.1 碰撞体策略

| 物体类型 | 碰撞方案 |
|----------|----------|
| 地形 | 高度图碰撞，逐顶点 |
| 建筑（亭、桥、摊） | 简化盒体 + 地板面，不用网格精确碰撞 |
| 树干 | 圆柱体碰撞，半径 = 树干半径 ×1.2 |
| 石灯笼、鹿威し | 圆柱体碰撞，**可被剑技击碎**（见 `07`） |
| 樱花树冠 | **无碰撞**。VR 中头部穿过树叶是可接受的，且省大量性能 |
| 水面 | 有碰撞（视为可行走地面），但材质半透明——玩家会看见自己"走在水面上"，此为 α 阶段已知妥协，⚠️ 后续改为不可行走 |
| 花瓣粒子 | 无碰撞 |

### 6.2 导航网格

NavMesh 只在**交战区**生成（樱花林、奥之森、石灯笼小径），安全区不需要敌人寻路。

| 参数 | 值 |
|------|-----|
| Agent 半径 | 0.35m（樱鬼）／0.5m（绯甲武者） |
| Agent 高度 | 1.4m / 1.9m |
| 最大坡度 | 25° |
| 最大跨越高度 | 0.3m |
| Cell Size | 0.25m |

### 6.3 边界处理

| 方向 | 手段 |
|------|------|
| 南（入口） | 鸟居 + 石垣，明示「这是门」。门外 5m 起雾浓度 100%，物理墙位于雾中 |
| 东、西 | 密集樱树丛（株距 1.2m，人不可通过）+ 地形抬升 0.8m |
| 北 | 奥之森尽头为断崖式地形跌落 + 浓雾 |
| 全域兜底 | 距边界 3m 处布置不可见碰撞墙，高度 8m |

玩家靠近边界 2m 内时，**不弹提示、不锁定视角**，仅让雾浓度线性上升。这是刻意的克制——文字提示会打破沉浸，而雾是庭园本身的语言。

## 七、樱吹雪分布

樱吹雪（Sakura Blizzard）是区域的核心视觉符号，但全程等密度会失去层次，也拖累性能。分布如下：

| 分区 | 花瓣密度（相对值） | 风向 | 备注 |
|------|-------------------|------|------|
| 鸟居参道 | 0.3 | 北 → 南 | 稀疏，避免入口遮挡视线 |
| 茶摊 | 0.4 | 北 → 南 | 摊棚遮挡一部分 |
| 镜池·太鼓桥 | **1.0** | 西北 → 东南 | 最密。花瓣落水产生涟漪是重点演出 |
| 樱亭 | 0.7 | 西北 → 东南 | 从亭内向外看密度最高，框景效果 |
| 枯山水 | 0.5 | 西 → 东 | 花瓣落在白川砂纹上，与耙纹形成对比 |
| 石灯笼小径 | 0.4 | 南 → 北 | **风向反转**，暗示进入异质空间 |
| 樱花林 | 0.8 | 乱流 | 战斗区，花瓣会遮挡敌人轮廓，密度受战斗状态抑制（见下） |
| 奥之森 | 0.2 | 几乎无风 | 压抑。花瓣稀少本身就是危险信号 |

**战斗状态抑制规则**：进入交战后，当前分区花瓣密度 ×0.4。理由是花瓣在 VR 中会遮挡敌人前摇动作，直接影响玩家读招能力——这是玩法问题，不是纯美术问题。脱战 4 秒后恢复。

花瓣生命周期：生成 → 飘落 6–9 秒 → 落地 → 停留 12 秒 → 淡出 1.5 秒。**不堆积**，避免透明排序开销与视觉脏乱。

## 九、切换系统几何验证

上游 `SwitchingSystem.md` 要求「目视队友 ≤15 米」。逐分区验证**最远两点距离**：

| 分区 | 最远两点 | 是否满足 |
|------|----------|----------|
| 鸟居参道 | 14.6m（矩形对角） | ✓ |
| 茶摊 | 7.8m | ✓ |
| 镜池·太鼓桥 | 14.8m（直径） | ✓ |
| 樱亭 | 9.9m | ✓ |
| 枯山水 | 14.9m | ✓ |
| 石灯笼小径 | 13.6m | ✓ |
| 樱花林 | 14.0m（直径） | ✓ |
| 奥之森 | 14.0m（直径） | ✓ |

全部满足，余量 0.1–7.2m。

**但存在跨分区问题**：两个相邻分区的玩家最大距离可达 15 + 分区间距。例如镜池（r=7.4）与樱亭（中心距 11.4m）之间，最远两点为 7.4 + 11.4 + 3.5 = 22.3m，超出 15m。

处理方式：这**不是缺陷，是设计意图**。切换是战斗系统，战斗只发生在交战区。交战区中：
- 樱花林 ↔ 石灯笼小径：中心距 10.4m，最远两点 7.0 + 10.4 + 6.8 = 24.2m ✗
- 樱花林 ↔ 奥之森：中心距 15.6m，最远两点 7.0 + 15.6 + 7.0 = 29.6m ✗

跨区切换超限。α 阶段的解法：**在战斗逻辑中将「樱花林 + 石灯笼小径 + 奥之森」视为单一交战域（Combat Domain）**，切换距离判定按玩家实际坐标计算而非按分区，同时在这三区内布置 3 处「呼应石」（可站立的扁平石台），刻意拉近队友可能的分布范围。

⚠️ 此为 α 阶段妥协方案。若后续要求严格分区切换，需缩小分区半径至 5m，将导致区域总面积增加约 40%，与箱庭的紧凑性冲突。**建议保持现方案，并在此登记为已知限制。**

## 十、场景布局数据

本文档所有坐标、尺寸、朝向的**机器可读版本**见同目录 `SceneLayout_SakuraTeien.json`。

规则：
1. JSON 是坐标的**唯一权威来源**，本文档表格为人读摘要；两者不一致时以 JSON 为准并回改本文档。
2. 引擎侧不得手改坐标。任何布局调整先改 JSON，再由导入脚本重新生成场景。
3. JSON 为引擎无关格式，字段定义见 `03_ArtAssetSpec_Procedural.md` 第四节。
